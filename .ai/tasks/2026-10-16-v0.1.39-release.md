# RELEASE-V0.1.39: Chuẩn hóa Color Primaries & Sửa lỗi Gateway Circuit Breaker

- Trạng thái: Đã triển khai; đã kiểm chứng build và runtime cục bộ.
- Người thực hiện: Antigravity
- Thời gian: 2026-10-16

## Mục tiêu và nghiệm thu

- Ngăn chặn lỗi render FFmpeg (exit code -129 / unsigned DWORD 4294967167) khi video đầu vào chứa color_primaries / colorspace = reserved hoặc unknown.
- Thắt chặt regex bắt mã HTTP error trong Gemini Gateway để không nhận nhầm mã thoát process (4294967167) thành HTTP 429, tránh kích hoạt nhầm Circuit Breaker.
- Tinh chỉnh UI trạng thái phục hồi AutoShort và bổ sung bộ lọc phân trang chương Facebook Reels.
- Đảm bảo toàn bộ quy trình typecheck, test suites, fonts, và đóng gói package:win hoàn toàn sạch sẽ.

## Thay đổi chính

- `src/main/canonicalDisplayGeometry.ts`: Bổ sung kiểm tra `needsColorNormalization` và tự động gắn `setparams=color_primaries=bt709:color_trc=bt709:colorspace=bt709` vào filter graph của FFmpeg khi gặp color metadata bất thường.
- `src/main/burn.ts`: Truy vấn `color_space`, `color_primaries`, `color_transfer` trong ffprobe; chèn bộ chuẩn hóa màu vào luồng render; chuẩn hóa mã lỗi âm (-129).
- `src/main/geminiGateway.ts`: Đổi regex `/405|429/` thành `/\b(?:405|429)\b/`.
- `src/renderer/src/components/AutoShort.tsx`: Sửa điều kiện recovery status tránh hiển thị sai "Phục hồi thời lượng lượt X/2" khi bị nghẽn provider.
- `src/main/facebookArticle.ts`: Lọc sibling chapter titles và cải thiện phát hiện inline chapters.
- Unit tests: `tests/canonical-display-geometry.test.ts`, `tests/autoshort-ocr-burn.test.ts`, `tests/gemini-gateway-contract.test.ts`.
