# STTN subtitle removal — approved design

Approved by the user in chat on 2026-09-05 ("duyệt"). Implement in the existing feature checkout, preserving the earlier uncommitted title/OCR/render changes on which this feature depends. Do not publish or commit unrelated work.

- Auto Short adds `blurMode: 'sttn'`, under the existing `lamMo` enable switch. Legacy manual and OCR blur retain their behavior. STTN requires visual OCR and uses the accurate profile.
- One optional `sttn-engine` runtime, one pinned STTN checkpoint downloaded separately on demand into managed userData. No GUI, training code, OCR, LaMa, or ProPainter dependencies are included. Runtime and model require hashes and version checks. No inference network access.
- Worker protocol `sttn-engine/1`: `--version`; `--probe --model PATH --provider auto|cuda|cpu`; `--run --request PATH`. Stdout JSONL events `version`, `probe`, `progress`, `done`, `error`; bounded diagnostics on stderr. Worker does not silently substitute blur.
- Request JSON: `inputPath`, `outputPath`, `timelinePath`, `modelPath`, `ffmpegPath`, `ffprobePath`, `provider`, `maxFrames` (12 default), optional `previewSeconds`. Timeline is the existing validated OcrVisualTimeline. Dimensions refer to canonical display space. Frame timestamps are normalized against first decoded PTS; output preserves their spacing.
- Decode incrementally, process small overlapping windows within scene boundaries, use context crop around active text and fixed model input geometry. Derive an inpainting mask from original OCR boxes, cover edges/shadows, and composite only into that mask at full resolution. Frames outside active ranges remain unchanged before encoding. Empty masks skip inference. CUDA OOM retries a smaller window in the same provider; exhausted retries fail explicitly.
- Produce a lossless FFV1 intermediate preserving source audio for subsequent existing burn/mix logic. Validate dimensions, timestamps/duration/audio before final render. Check free temporary disk; cleanup on cancellation/failure. Bound RAM independently of video length; no full-video PNG extraction by the new worker.
- Source OCR/SRT is obtained before erasure and remains the source for translation/title generation. A selected STTN job clears manual rectangles and disables Gaussian blur for its final render. Title, TTS and output folder naming retain existing behavior.
- GUI exposes a short preview using the same worker. Model loads only during probe/run; no background server. First release qualifies Windows NVIDIA CUDA; report effective provider and CPU availability honestly.
- Verification: behavioral contract tests, real mask/window/composite tests, process failure/cancellation tests, pipeline integration, typecheck/build, real model inference on synthetic known-background media and a short source clip. Record quality, time, VRAM and limits; packaged/release availability is distinct from source implementation.
